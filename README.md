## 01 / 正在构建

<a href="https://github.com/xiaohengyu8226-png/tcm-extract-engine">
  <img src="assets/project.svg" width="100%" alt="打开 tcm-extract-engine：从医学文献到可追溯知识的抽取引擎。" />

**[TCM Extract Engine ↗](https://github.com/xiaohengyu8226-png/tcm-extract-engine)**

从 PDF / Markdown 出发，把文档解析、领域规划、结构化抽取、原文核验和人工审核串成一条流水线。支持通用知识与中医安全审方领域，也在探索通过 GEPA 反馈改进提示词。

`文档解析` · `结构化抽取` · `证据追溯` · `人工复核` · `提示词进化`

<img src="assets/pipeline.svg" width="100%" alt="当前项目的知识处理闭环：阅读原文 → 规划 → 抽取 → 核验 → 反馈优化。" />

## 02 / 关注的方向

| 方向 | 关注内容 |
| :--- | :--- |
| **大模型算法 · LLM Algorithms** | 关注模型训练与适配、推理能力优化，以及可靠的效果评估。 |
| **多模态算法 · Multimodal Learning** | 关注文本、图像等模态之间的理解、对齐与融合。 |
| **RAG · 检索增强生成** | 关注知识检索、上下文组织，以及有来源支撑的生成结果。 |
| **医疗 AI · Medical AI** | 关注大模型与多模态技术在医疗场景中的应用、验证与安全边界。 |

> 先保留证据，再判断结果。自动核验后，仍然需要人工复核。
