# Profile design

Theme: a dark knowledge lab. Ink green `#0b1514`, warm paper `#f0f0dc`, signal green `#b2f178`.

The four SVGs in `assets/` are original, self-contained graphics with no JavaScript, embedded credentials, external fonts, or external image dependencies. CSS animation adds a subtle signal flow, with a static fallback and reduced-motion support where available. GitHub may cache or suppress animation depending on the rendering client.

Edit `README.md` for profile text. Edit the SVGs for visual changes. The profile contains only public project information; it does not publish personal contact details, private repository statistics, or private activity. The only third-party images are public technology badges from Shields.io.

Inspired by the resource categories in [beautify-github-profile](https://github.com/rzashakeri/beautify-github-profile). No copied profile artwork or fabricated metrics.
